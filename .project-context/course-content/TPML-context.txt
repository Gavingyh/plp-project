2. DAY-BY-DAY CONTENT
 
--- DAY 1 — Classic DNN for Text Processing (Dr. Wang Aobo, 76 slides) ---
 
Opening / motivation ("What can NLP do?"): frames NLP around Classification (sentiment/spam/emotion detection) and
Extraction (NER, illustrated with a tagged-tweet example — sportsteam/geo-loc/company/product/tvshow tags on real
tweets). Lists "fancier" use cases (recommendation, search, QA, voice assistants, MT, grammar correction, chatbots,
fake-content generation/detection), then a "moment NLP became useful" retrospective (autoSmry GPT-3 summarizer,
GitHub Copilot 2021, DALL-E 2 2022's "astronaut riding a horse" prompt, and a chain-of-thought worked example via
LaMDA 2/PaLM correctly generalizing a tennis-ball word problem to a "how many hours in May" question, 31×24=744) —
setting up the day's theme of NLP "with or without Reasoning."
 
Data splits & evaluation: DNNs are always supervised except Reinforcement Learning. Hold-Out Evaluation
(Train/Validation/Test) vs K-Fold Cross Validation (worked k=3 example with sklearn's `train_test_split`/`KFold`),
plus a separate held-out Test set evaluated only after training completes.
 
Over/underfitting and regularization — the day's most rigorously worked section:
- Classic bias/variance three-panel chart, deliberately debunking the claim that only "outdated" methods (Naive
  Bayes/LogR/SVM) suffer under/overfitting while "latest Deep Learning has no such problems."
- Overcoming underfitting (train longer, more capacity, cleaner data) vs overfitting (less capacity, weight
  regularization, dropout).
- Weight regularization derived in full: Cost = Loss + regularization term; L1 = Loss + (λ/2m)·Σ‖w‖ (can drive
  weights to exactly zero); L2 = Loss + (λ/2m)·Σ‖w‖² (shrinks toward but never to zero); λ typically ∈
  {0.01, 0.1, 1}. A fully worked gradient-descent numeric example minimizes a toy loss L=w²−4w+6 via the delta rule
  (η=0.3, w₀=3) three ways — no regularization converges to w=2.00, +L1 converges to w=1.00 (demonstrating zeroing),
  +L2 also converges to w=1.00 but explicitly "has no chance to be 0" — contrasting L1's zeroing effect with L2's
  shrink-but-never-zero effect. A one-hot-vocabulary word-classification example shows L1 zeroing a weight as
  equivalent to reducing model dimensionality.
- Dropout: worked (4,6)-activation × (6,6)-mask matrix example at P=0.5; distinguishes Naive Dropout RNN
  (independent random masks every timestep) from Variational RNN/Dropout (Gal & Ghahramani, arXiv:1512.05287 — same
  mask reused across all timesteps in a sequence), with the paper's train/test curves showing Variational LSTM
  generalizes better (lower test error) than Standard/Naive Dropout LSTM over training.
 
CNN for text classification: reframes the convolutional kernel as an n-gram feature extractor (kernel shaped
(ngram, embedding_dim), sliding 1-D along text, not 2-D like image CNNs); explicitly distinguishes convolution from
plain matrix multiplication via a worked numeric 2-gram example (0.5×0.7+0.4×(−0.5)+0.7×0.3+0.2×0.1+(−0.1)×0.2+
0.3×0.6 = 0.54, sliding to the next window). MaxPooling collapses each kernel's sliding outputs to one scalar
(worked example [0.3,−0.2,0.8,0.63,−0.4]→0.8). Multi-kernel architectures run parallel kernels (different n-gram
patterns), each maxpooled and concatenated. Full pipeline: convolution → maxpool per kernel → flatten → optional
dropout → dense → softmax.
 
RNN and LSTM: motivates RNNs from text's sequential nature; unrolled-cell view with shared weights across
timesteps. RNN/Bi-RNN encoders build a running sentence representation (concatenating forward+backward hidden
states in the bi-directional case). Vanilla RNN cell: h' = tanh(w_ih·x + b_ih + w_hh·h + b_hh). RNN as classifier
(final hidden state → dense → softmax) vs sequence labeller (a predict head at every timestep). Vanishing gradients
shown explicitly (d(loss)/dh tiny at early timesteps, large at later ones) as the motivation for gated memory.
An "LSTM Gallery" slide surveys diagram conventions across sources (Hochreiter & Schmidhuber 1997, Chris Olah 2015,
Schmidhuber 2017, Neubig 2019, deeplearning.net, Wikipedia) before teaching one consistent version, built up over
three slides: memory cell C_t passed forward and gated by forget/input/output sigmoid gates plus a tanh candidate
branch — matching the standard LSTM equations — then collapsed into a single black-box "LSTM" unit. Explicitly
notes vanishing gradients are a general nested-function/DNN problem, not RNN-exclusive, and that LSTM/GRU reduce
but don't eliminate it. RNN family comparison: Vanilla (obsolete) vs LSTM (most popular, usually bi-directional) vs
GRU (simplified, faster, weaker). LSTM dropout repeats the Naive-vs-Variational distinction from the regularization
section with the same arXiv:1512.05287 empirical curves.
 
Sequence-to-sequence: motivated by asking "what if a decoder RNN's initial state h₀ were generated by another RNN
(an Encoder)?" — the Encoder-Decoder architecture, generalized as "translate any object A to object B" (French↔
English, Image↔Text, Audio↔Text, Document↔Summary, Question↔Answer), with the caveat that this needs large paired
condition/target data.
 
Bridge to Day 2 (Language Models / "ImageNet moment for NLP"): frames LM pretraining as needing large
labeled/representative data (cloze example: "The service was poor, but the food was ___") to capture long-term
dependencies and hierarchy, exploiting the abundance of plain text. ELMo (2017) walked through as stacked-Bi-LSTM
language modeling (concatenating forward+backward LSTM outputs per word). Timeline slides plot GloVe (2014) → ELMo
& ULMFiT (2018, LSTM-based) → the Transformer/"Attention" moment (2018) → GPT and BERT (Oct 2018), tied to hardware
progress (NVIDIA GPUs, Turing Award) and closing with a scale comparison: BERT (24 blocks/1024 hidden/340M params,
16 TPU pods) vs GPT (12 blocks/37 layers, 1 month on 8 GPUs) vs ELMo (4096 units/512 dims, single GPU) — directly
setting up Day 2's Attention & Transformers content.
 
--- DAY 2 — Advanced DNN systems: Attention & Transformers (Dr. Wang Aobo, 80 slides) ---
 
Opens by recapping the Seq2Seq/encoder-decoder framing from Day 1, then the "(Large) Language Models as NLP's
ImageNet moment" and ELMo material largely mirrors Day 1's bridge section (same timeline motif recurs three times
with escalating architecture detail: BERT 24 blocks/1024 hidden/340M params/16 TPU pods; GPT 12 blocks/37
layers/1 month on 8 GPUs; ELMo 4096 units/512 dims/single GPU).
 
Attention mechanism: framed via psychology (selective concentration) and motivated by vanishing gradients plus a
single fixed context vector "C" not capturing enough long-range information in vanilla Seq2Seq. Worked example:
"Laurent lives in France and he speaks excellent ___" — attention weights point back to "France" to predict
"French."
- Bahdanau (additive) attention (2015): at each decode step, attention weights α computed over ALL encoder hidden
  states (not just the last) plus current decoder state, scored via a tanh(Wₕ·h + Wᵢ·x) box then softmax, producing
  a weighted-sum context vector.
- Luong attention: uses only the top hidden layer of encoder/decoder; scores via multiplicative similarity
  functions (three alternatives given).
- Global (Bahdanau, cost grows with sequence length) vs local (windowed) attention.
 
Transformer ("Attention is all you need" — foundation of BERT/GPT-2/3/4):
- Encoder block: multi-head self-attention → Add&Norm → feed-forward → Add&Norm. Decoder block: masked
  multi-head self-attention → encoder-decoder cross-attention → feed-forward, each with residual Add&Norm.
- Self-attention worked example ("I kicked the ball" — "kicked" attends to "I"/itself/"ball"); mechanics: Q=X·Wᵠ,
  K=X·Wᴷ, V=X·Wⱽ, Z = softmax(QKᵀ/√dₖ)·V.
- Multi-head attention: original paper's 8 heads, each a "representation subspace," concatenated and projected
  by Wᴼ. Positional encoding: sinusoidal "time signal" added since self-attention has no inherent order sense.
- Causal masking (−∞ on future positions in decoder self-attention) walked through as a full step-by-step
  autoregressive decode (6 steps to `<end of sentence>`).
- Efficiency add-ons (clearly newer material grafted onto the 2017 core): FlashAttention (explained via GPU
  memory hierarchy SRAM/HBM/DRAM bandwidth, fusing matmul/mask/softmax/dropout/matmul into one kernel to cut DRAM
  reads); MHA vs GQA vs MQA compared for KV-cache/inference cost (MQA ~30-40% faster with a quality drop; GQA as
  the trade-off) backed by a LLaMA-2 benchmark table (BoolQ/PIQA/SIQA/HellaSwag/ARC/NQ/TQA/MMLU/GSM8K/HumanEval)
  showing GQA near-MHA quality; Multi-Head Latent Attention (MLA, DeepSeek-V2, arXiv:2405.04434) as low-rank
  joint K/V compression into a cached latent vector.
- A deliberately contrarian pair of slides ("fighting the direction of research") contrasts an 8-head Transformer
  (8 GPUs × 3.5 days, Google 2017) against Stephen Merity's Single-Headed-Attention LSTM (SHA-LSTM, 2019 — 4
  layers, 51-54M params, 1 GPU × 1 day) reaching comparable perplexity to some Transformer-XL variants — questioning
  whether Transformers pay a "complexity tax."
- BERT (encoder-only): Masked LM (mask 15%, predict via FC+GELU+Norm head) + Next Sentence Prediction
  ([CLS]/[SEP], sentence A/B pairs); Base (12 layers) vs Large (24 layers). GPT-2/3 (decoder-only): stacked masked
  self-attention + feed-forward blocks with text-prediction and task-classifier heads.
- "No Silver Bullet" (2020) case study: on political-perspective detection, simple baselines (SVM/LogReg/LSTM)
  beat fine-tuned BERT and Swivel embeddings (arXiv:2009.07238) — a caution against assuming bigger pretrained
  models always win.
- Scaling charts: GPT-1 (117M, Jun-18) → BERT-large → GPT-2 → Meena → Turing-NLG → GPT-3 (175B) → T5-XXL (1.6T,
  Jan-21), extended with Megatron-LM (8.3B) and Megatron-Turing NLG (530B).
 
Sentence/document representation: Sentence-BERT (SBERT, 2018) in both siamese-tower forms (cosine-similarity
regression; (u,v,|u−v|)→softmax classification), with a runnable `sentence_transformers` example
(all-MiniLM-L6-v2, cosine 0.82 for related ML/AI sentences vs 0.12 for an unrelated one) and a checkpoint
comparison table. Generation-evaluation metrics contrasted: BLEU (precision-based, MT) vs ROUGE (recall-based,
summarization) via a worked contrastive example, then BERTScore (2020, embedding cosine similarity, IDF-weighted
max per reference token). Pivots to applied tooling: LangChain's RAG pipeline (raw data → chunking → vector store
→ prompt engineering ↔ LLM ↔ UI) and an embedding-provider comparison table (OpenAI ada-002, HuggingFace
sentence-transformers, Cohere, Google Vertex AI/PaLM, Azure OpenAI, Anthropic, FastEmbed). Closes with practical
guidance: averaging word vectors is a strong document-embedding benchmark; BERT (max length 512) is a reasonable
default absent a task-specific leader.
 
--- DAY 3 — Transfer Learning with Pre-trained Models (Dr. Fan Zhenzhen, 92 slides) ---
 
The largest and most benchmark-heavy of the four days.
 
Transfer learning foundations: reuse a Source-Domain model's learned weights/representations on a small-data
Target-Domain task instead of training from scratch (feature reuse, less labelled data, faster/cheaper training,
better generalization). Draws the direct CV↔NLP analogy: 2012 ImageNet/AlexNet ↔ 2018 NLP "ImageNet moment"
(ELMo/ULMFiT/GPT/BERT). Two pretraining objectives contrasted: Language Modelling (autoregressive, unidirectional,
unlimited self-supervised data, no future context — GPT family) vs Masked Language Model (Cloze-style, mask ~15%,
full bidirectional context — BERT/RoBERTa/ALBERT/ModernBERT), each with a worked cloze example. Milestone timeline:
Word2Vec/GloVe (2013-14) → Transformer (2017) → ELMo → ULMFiT (Howard & Ruder — pioneered NLP transfer learning) →
BERT → GPT → T5 (2019).
- Five transfer-learning approaches with diagrams and a decision table (data needed / compute cost / worked
  example) plus a "Quick Guide" heuristic (start zero/few-shot → fine-tune → PEFT if too costly → domain-adapt
  first if domain mismatch): (1) Feature Extraction (pretrained model frozen, only a new head trained); (2)
  Fine-tuning (all/selected layers trainable + new head; standard for BERT-base 110M/T5-small 60M; PEFT/LoRA
  flagged as "covered in Day 4" for large models); (3) Domain Adaptation (general pretrain → domain-adaptive LM
  training on unlabelled domain text → task fine-tune; exemplified by BERT→BioBERT and BERT→LegalBERT); (4)
  Multi-task Learning (one shared backbone across translation/summarization/QA/NER, exemplified by T5's
  span-corruption + joint fine-tuning); (5) Zero-/Few-shot Learning (in-context, no gradient updates, needs scale
  e.g. GPT-3 175B; worked sentiment-prompt examples both ways).
- Subword tokenization compared: WordPiece (BERT family, ~30K vocab, "##" continuation) vs BPE (GPT-2/3, RoBERTa,
  ~50K vocab, frequency-based merges) vs SentencePiece (T5/LLaMA/XLNet/ALBERT, ~32K vocab, "_" for whitespace) —
  warns mismatched tokenizer/model pairing breaks results.
 
Representative pre-trained models:
- Two historical-arc timelines (2013-2019 then 2020-2025) tracing Word2Vec through GPT-4/Mistral/Gemini/LLaMA
  3-4/DeepSeek V3/Qwen 2.5/Claude 4/GPT-5, framed as two parallel trends: frontier LLMs pushing capability, and
  small distilled models (Phi-4, Gemma 2, Mistral, DeepSeek-R1-distilled 1.5B-70B) democratizing fine-tuning. A
  "Historical Shift" table frames four eras (Static Representations → Pretrain-Finetune → Prompt & Instruction →
  Foundation & Reasoning Models).
- Three pretrained-Transformer types with strengths/best-uses: Encoder-only/Auto-encoding (BERT family — MLM,
  bidirectional, best for classification/NER/QA); Decoder-only/Auto-regressive (GPT/LLaMA/Mistral — LM objective,
  best for generation/chat/code); Encoder-Decoder/Seq2Seq (T5/BART/Flan-T5 — span-corruption, best for
  translation/summarization).
- BERT deep dive: Base (12L/768H/12heads/110M) vs Large (24L/1024H/16heads/340M); pretrained on BooksCorpus (800M
  words) + Wikipedia (2,500M words); compared against GPT (left-to-right) and ELMo (concatenated independent
  directions) via Devlin et al.'s Figure 3 — only BERT is jointly bidirectional in every layer. Two pretraining
  tasks (MLM; NSP — later found droppable per RoBERTa 2019 without hurting performance). BERT-for-feature-
  extraction (Jay Alammar): concatenating the last four hidden layers gives the best CoNLL-2003 NER F1 (96.1) vs
  using just the first or last layer. Fine-tuning task patterns (Devlin Fig.4) with typical hyperparameters
  (batch 16/32, LR 5e-5/3e-5/2e-5, 2-4 epochs). Benchmark results: GLUE 80.5% (+7.7 over prior SOTA), SQuAD v1.1
  F1 93.2, SQuAD v2.0 F1 83.1.
- Model compression: quantization (FP16/INT8), pruning, knowledge distillation (TinyBERT-style attention +
  hidden-state distillation losses). Comparison: DistilBERT (6L, 66M, 1.6× faster, ~97% of BERT's GLUE) vs TinyBERT
  (4L, 14.5M, 9.4× faster, comparable GLUE) vs ALBERT (cross-layer parameter sharing, 12M-235M, exceeds BERT at
  82.3) — notes DeepSeek-R1 (Jan 2025) used distillation for its 1.5B-70B reasoning models.
- ModernBERT (Dec 2024, Answer.AI/LightOn): RoPE (8,192-token context vs BERT's 512), unpadding, GeGLU, alternating
  local/global attention, Flash Attention, 2T tokens incl. code/math — quantified as 16× longer context, ~600×
  more training data at comparable param counts (149M/395M).
- GPT & GPT-2: GPT (2018) — 117M, 12 decoder layers, two-phase training (unsupervised pretraining on BooksCorpus's
  7,000 books, 100 epochs; supervised fine-tuning per task, batch 32/LR 6.25e-5/3 epochs). GPT-2 (2019) — four
  sizes (124M-1.5B), WebText (8M pages/40GB), BPE vocab 50,257, 1,024-token context, "LM as multi-task learning,"
  staged Feb-Nov 2019 release over misuse concerns; improved SOTA zero-shot on 7/8 LM datasets.
- Decoding methods: Greedy (argmax, fast/deterministic/repetitive) vs Beam Search (top-k sequences, worked k=2
  tree, n-gram penalty fix) vs Top-k Sampling vs Top-p/Nucleus Sampling, plus temperature scaling
  (P_i=exp(z_i/T)/Σexp(z_j/T); T→0 greedy, T=1 default, T>1 creative, T≫1 chaotic/hallucination-risk) and a
  decoding-parameter guide table by task (factual QA: greedy/beam T 0.1-0.3; translation: beam k=4-5; creative/
  code/brainstorming: top-p with wider T/p ranges).
- T5 & Flan-T5: T5 (2019) — Span Corruption pretraining on C4 (~750GB); five sizes 60M-11B; unifies every task as
  text-to-text via task prefixes ("translate English to German:", "summarize:"); "bigger is better — a smaller
  model on more data was often outperformed by a larger model on fewer steps." Flan-T5 (2022) — instruction-tuned,
  natural-language instructions replacing rigid prefixes, 1,800+ tasks/400+ datasets incl. chain-of-thought
  examples, sizes 80M-11B — proof instruction fine-tuning boosts reasoning/generalization without growing
  parameters; bridges to Day 4.
 
Evaluation (extensive benchmark survey): GLUE's 9 tasks and SuperGLUE's harder successor; QA benchmarks (SQuAD
1.1/2.0, TriviaQA, NaturalQuestions); LLM-era benchmarks (MMLU 16K MCQs/57 subjects ~90% human baseline, MMLU-Pro,
GPQA "Google-proof" 448 MCQs); coding (HumanEval 164, MBPP ~1,000, Codeforces, APPS ~10K, SWE-bench 2,294 real
GitHub issues); math/reasoning (GSM8K 8,500, MATH 12,500, AIME 2024, ARC/PIQA/HellaSwag); specialized (multilingual
MMMLU/MGSM, long-context SCROLLS/"needle in a haystack," retrieval RQABench/STARK, tool-use BFCL/Nexus, Chatbot
Arena human-preference ranking); culminating in Humanity's Last Exam (Scale AI + Center for AI Safety — 2,500
multi-modal expert-authored questions from ~1,000 experts, built because MMLU/MATH/GPQA are saturating). Text-
generation metrics built from n-gram fundamentals up: BLEU (brevity penalty × geometric mean of n=1-4 precisions;
score-interpretation table <10 "almost useless" to >60 "better than human"; no synonym/order handling) vs METEOR
(harmonic-mean F-score, WordNet synonyms, stemming, order/chunk penalty) vs ROUGE (recall-oriented; ROUGE-N/L/S
variants) — all three flagged as correlating only loosely with human judgment; then semantic metrics BERTScore,
COMET (crosslingual, human-judgment-trained), BLEURT; then LLM-as-Judge as the paradigm for open-ended generation
(three modes: single-answer grading, pairwise comparison as in Chatbot Arena, reference-guided grading; known
biases: position, verbosity, self-enhancement; best practices: clear rubrics, position-swapping, multiple judges,
CoT judging, human calibration). A final table cross-references all seven metrics by type/focus/mechanism/best-use.
 
The rise of LLMs & concerns: GPT-3 ("Language Models are Few-Shot Learners," Jul 2020) — 175B, trained mainly on
filtered Common Crawl (570GB from 45TB raw) blended with WebText2/Books1/Books2/Wikipedia; "LM as meta-learner"
framing (outer-loop SGD pretraining, inner-loop in-context learning with no weight updates); the "larger models use
in-context learning better" scaling chart (175B vs 13B vs 1.3B accuracy vs number of in-context examples); GPT-3's
Turing-test-for-news result (human raters only 52% accurate distinguishing GPT-3-written articles from real ones).
Evolution chain to ChatGPT: GPT-3 → Codex (Aug 2021) → InstructGPT (Mar 2022, SFT+RLHF) → ChatGPT (Nov 2022) — RLHF
introduced via the canonical 3-step InstructGPT diagram (SFT demonstrations → reward-model training on
comparisons → PPO policy optimization against the reward model), flagged for more detail on Day 4. LLM
applications/limitations: seven use cases with an explicit "not sufficient alone" caveat (no persistent memory, no
real-time data, can't act, needs careful prompting) motivating RAG/agents/tools (RAG pipeline diagrammed end-to-
end: load → split → vectorstore → retrieve → prompt → LLM → answer; Agents as an LLM+Tools observe/act loop). Risks
and bias: DeepMind's six-category ethical/social risk taxonomy (Weidinger et al. 2021); gender-occupation bias
example; Schramowski et al. 2022 (Nature Machine Intelligence, LLMs encode human-like moral judgments from
training data); Carlini et al. 2021 training-data-extraction/memorization attacks; the 2023 Samsung/ChatGPT
data-leak incidents (source code, chip fault-test sequences, meeting minutes) and the resulting bank bans
(Bank of America, Goldman Sachs, Citigroup, Deutsche Bank, Wells Fargo) plus enterprise-governed tools like NUS
AI-Know; a summary table maps six limitations (bias, toxicity, hallucination, data leakage, environmental cost,
misuse) to research directions, each flagged for deeper Day 4 coverage. Generative AI beyond text: the same
transformer architecture tiled across Music (MuseNet/Jukebox/Suno/Udio), Images (DALL-E/Midjourney/Stable
Diffusion), Speech (Whisper/ElevenLabs/Bark), Video (Sora/Runway Gen-3), Multi-modal (CLIP/GPT-4V/Gemini), Code
(Codex/Copilot/Cursor). Closes with five takeaways (scaling drives capability; three architecture families each
excel differently; evaluation is multi-faceted; LLMs remain imperfect; small/distilled models remain essential for
cost/latency) and Fei-Lei Li's 2021 quote "The future of AI is not about man vs. machine, but man with machine."
 
--- DAY 4 — Trending Topics on LLMs (Dr. Wang Aobo, 68 slides) ---
 
Agenda: Model tuning with prompts/instructions (incl. LLaMA's family) → Parameter-Efficient Fine-tuning → MoE →
Workshop → Extra/trending topics → Exercise.
 
Fine-tuning with Instructions:
- Base LLM (next-token prediction on raw text) vs Instruction-Tuned LLM (fine-tuned on instruction→response pairs
  to follow instructions rather than just continue text) — the canonical two-types-of-LLM framing, with a worked
  SFT annotation example (helpfulness completion + a safety-refusal example) drawn from an InstructGPT-style paper
  table.
- Model Supervised Fine-Tuning (full model tuning): a separate full-size fine-tuned copy of the pretrained model is
  produced per task/batch (illustrated with the Bloomberg GPT case — 11B-param task-specific copies for Task
  A/B/C). Contrasted later with Prompt Tuning's shared-model approach.
- A benchmark chart (Arithmetic/Commonsense/Symbolic/Logical Reasoning + RTE/CB/BoolQ/MuTual/SAMSum/CoNLL03/SST2)
  compares ChatGPT vs GPT-3.5 vs a fine-tuned model — fine-tuning wins or ties on most tasks, especially symbolic
  reasoning (Last Letter, Coin Flip) where it dramatically outperforms both general models.
 
LLaMA's family:
- "Evolutionary Tree" of LLMs (2018-2023): traces encoder-only (BERT lineage), encoder-decoder (T5/BART lineage),
  and decoder-only (GPT lineage) branches, open- vs closed-source, converging toward LLaMA (Meta) as the dominant
  open-source root for 2023-era derivatives.
- Alpaca pipeline (Stanford): 175 human-written seed instruction tasks → fed to OpenAI text-davinci-003 via a
  "modified self-instruct" generation process → 52K generated instruction-following examples → supervised
  fine-tuning of Meta's LLaMA 7B → Alpaca 7B. This is the template most cheap/small-scale instruction-tuning
  projects since have copied.
- A second family tree specifically for the open-source instruction-tuned lineage: LLaMA → Alpaca → {Alpaca-LoRA →
  Chinese-Alpaca-LoRA, Chinese-Vicuna}; parallel branches from T5 (→Flan-T5/T0/mT0), GLM (→ChatGLM), BLOOM
  (→BELLE, BLOOMZ). Closed-source branch shown separately: ERNIE 3.0→ERNIE Bot, GPT-3.0→GPT-3.5→ChatGPT,
  LaMDA→FLAN/Bard, PaLM→Flan-PaLM.
 
Prompt Tuning (Lester et al. 2021, "The Power of Scale for Parameter-Efficient Prompt Tuning"):
- Contrasted directly with full Model Tuning: instead of a separate full-size model copy per task, Prompt Tuning
  learns a small task-specific "soft prompt" (~20K params) prepended to a shared frozen pretrained model; a
  mixed-task batch can be served by one shared model.
- SuperGLUE-score-vs-model-size chart: Prompt Tuning underperforms full Model Tuning at small scale but converges
  to match it as parameter count grows past ~10^10 — the deck's key takeaway is "prompt tuning prefers larger
  models" and "prompt engineering [manual prompt writing, no training] is not good enough" by comparison.
 
Parameter-Efficient Fine-tuning (PEFT) — three families, illustrated on one recurring transformer-block diagram
(Houlsby et al. figure, reused across ~8 slides with different families highlighted):
- Adapters (Houlsby 2019, Pfeiffer 2021 variant): small bottleneck feed-forward blocks inserted after attention
  and FFN sublayers; only these are trained. Formula: h ← h + f(h·W_down)·W_up (down-project, nonlinearity,
  up-project, residual-add).
- Prefix-tuning / Prompt Tuning (used near-interchangeably in this deck, with the slides noting "usually [prefix
  tuning] refers to prompt tuning"): learnable "soft prompt" vectors prepended to K and V at each attention layer
  (or as an input-embedding prefix); trained via backprop while the base model is frozen. Also covered: P-tuning
  (an LSTM/MLP "prompt encoder" that generates pseudo-prompt embeddings instead of using raw embeddings directly,
  to help the pseudo-prompts interact contextually).
  Cross-domain analogues in computer vision were also shown: Visual Prompt Tuning (VPT, 2022 — learnable prompt
  tokens inserted into a frozen ViT, deep or shallow variants) and Context Optimization (CoOp, 2022 — learnable
  context vectors replacing hand-written CLIP prompt templates like "a photo of a {class}").
- Low-Rank Adaptation (LoRA, Hu et al.): freezes the pretrained weight matrix W₀ and adds a low-rank update
  h = W₀x → h = (W₀ + BA)x, where B is initialized to zero and A to a small Gaussian, and the rank r ≪ d keeps the
  added parameter count tiny; applied to the Q/K/V projection matrices in the diagram.
 
MoE (Mixture-of-Experts): shown via the DeepSeekMoE progression — (a) conventional top-2 routing over N experts →
(b) fine-grained expert segmentation (more, smaller experts, top-4 routing) → (c) shared-expert isolation
(DeepSeekMoE: one always-on shared expert + routed experts, top-3) — the point being each step increases expert
specialization without proportionally increasing active compute per token.
 
Trending/Extra topics (this is the bulk of the deck's back half):
- Scaling Laws (Kaplan et al. 2020): test loss falls as a power law against compute, dataset size, and parameter
  count — framed as "'linearly' increase exponentially" (log-log straight lines mean exponential real-world cost
  for linear-looking loss gains).
- Emergent Phenomena: an ability is "emergent" if absent in smaller models but present in larger ones (BIG-Bench
  task charts, MMLU comparison table across GPT-NeoX/GPT-3/Gopher/Chinchilla/PaLM/LLaMA sizes, chain-of-thought
  prompting example on the classic "tennis balls" arithmetic word problem, and charts showing sudden jumps in
  instruction-following/8-digit-addition/calibration only past a FLOPs threshold). Practical guidance given
  verbatim: 13B models are "very basic, not likely to deal with logic heavy tasks accurately"; 40-50B "could be
  possible"; "better to start from 70B" for logic-heavy work.
- Grokking: a proposed alternate explanation for emergence — a model can hit 100% train accuracy early while
  staying at random-guess test accuracy for a long time, then suddenly generalize much later in training.
- The "Impossible Triangle" (efficient-sequence-model framing): Transformers get strong performance + training
  parallelism but not low-cost inference; RNNs get low-cost inference + parallelism-ish training but weaker
  performance; the triangle motivates RetNet as a model claiming all three via a dual parallel/recurrent
  formulation ((QKᵀ⊙D)V in training ≡ a recurrent state update at inference), shown with GPU memory/throughput/
  latency benchmarks against Transformers (3.4x–15.6x better on the reported metrics).
- Newer efficient-attention architectures name-checked with diagrams: Qwen3.8-Flash-Next (interleaved QSA/GDN
  layers + MoE + an N-gram embedding layer), Gated DeltaNet (approximates softmax attention's exp(qᵀk) via a
  first-order Taylor expansion, exp(x)≈1+x, to get a linear-attention-like recurrence), and Qwen Sparse Attention
  (QSA — a lightweight indexer compresses the sequence into micro-blocks, scores block-level importance, and a
  top-k selector restricts full attention to the most relevant blocks).
- Evaluation: a slightly cynical practical section on how models/papers game "beats GPT-4" claims (swap scene
  order to expose an incomplete eval method, exploit linguistic barriers by mixing in Chinese/code/math tokens,
  pick exactly one beatable opponent model, choose a simple easily-described problem) alongside real benchmarks:
  SciQ (BLOOM/GPT-2/GPT-3/ChatGPT/LLaMA-13B compared across Chemistry/Biology/Physics/Earth-Science topics),
  C-Eval (a Chinese-language benchmark spanning STEM/Humanities/Social-Science/Other, incl. professional
  certification-style questions), and Humanity's Last Exam (a newer, much harder benchmark where even GPT-4o/o1/
  Claude Sonnet-3.5/Gemini-1.5 score in the single digits, unlike near-saturated MMLU/GPQA/MATH).
- Hallucination — the deck's most detailed sub-topic:
  - Two failure types: Faithfulness (contradicts the given input — split into Intrinsic, contradicting the input
    directly, and Extrinsic, inventing facts not verifiable from the input) vs Factualness (contradicts general
    common-sense/world knowledge).
  - Causes: (1) Data — poor training-data quality (a "wrong memory" example where a model answers from memorized
    facts even when the given context is edited to say otherwise; deduplicating near-duplicate training data is
    cited as improving models). (2) Prompts — vague prompts, fixed by being more specific, using role-play framing,
    supplying query+background content together, and general prompt engineering. (3) Sampling — top-p/nucleus
    sampling itself can induce hallucination (fix: beam search, or a "factual-nucleus sampling" variant with a
    dedicated claim-filtering/evidence-selection/factuality-evaluation pipeline). (4) Exposure bias — mismatch
    between teacher-forced training and free-running generation (domain shift); Minimum Risk Training (MRT, a
    sequence-level expected-risk objective instead of token-level MLE) is cited as a mitigation.
  - Detection: external-reference methods (compare against search engines/Wikipedia, BLEU/ROUGE against a
    reference, tools like LlamaIndex for RAG-style grounding, or a "Transformer Memory Network" that retrieves and
    re-encodes knowledge before generating) vs reference-free methods (FEQA — mask key spans in a summary, generate
    questions about them, and check whether a QA model answers the same way from the summary vs the source, using
    F1 as a "faithfulness" score; NLI/dependency-level entailment — check whether generated claims are entailed by
    the source at the level of individual dependency arcs, catching subtle errors like "Putin is president" →
    "Putin is U.S. president"; and a trainable factualness-classification metric built on annotated hallucination
    data).
  - Other mitigation tricks listed (each linked to a paper/technique in the deck, not elaborated): multi-task
    training mixtures, "sketch-to-content" two-stage generation, controllable grounded response generation via
    inductive attention, an RL reward function derived from an evolved BERT model, and post-hoc discriminative
    correction models.
- LLM Reasoning Failures: references a 2026 survey paper taxonomizing LLM reasoning failures across Informal
  (individual cognitive reasoning, implicit/explicit social reasoning — Theory of Mind, social norms, multi-agent),
  Formal (logic in natural language incl. the "reversal curse" and compositional reasoning, logic in benchmarks
  like math-word-problems and coding, arithmetic), and Embodied (1D/2D/3D physical/spatial reasoning, tool use,
  long-term autonomy) categories, cross-cut by Robustness/Limitation/Fundamental failure types.
- Exercise: "Fail the AI with your logical challenges" — a live class exercise trying adversarial/trick prompts
  against a chat model (examples given: writing a sentence using no words that appear in the Bible; a
  floor-counting riddle; the classic river-crossing-with-a-torch puzzle; the "poisoned wine bottle" info-theory
  puzzle; Hilbert's infinite-hotel paradox; GRE-style physics/rate word problems) — framed as a way to probe where
  current LLM reasoning still breaks.
 
Reference list (as given in the deck, for anyone chasing primary sources): Goyal & Durrett 2020 (dependency-level
entailment factuality), arXiv:2104.08691 (Power of Scale for Prompt Tuning), NVIDIA NeMo Multitask Prompt/P-Tuning
tutorial, arXiv:2206.04624, ACL 2020.acl-main.326, arXiv:2109.05052, arXiv:1811.01241, and a Pinecone blog post on
fixing hallucination with knowledge bases.
