The fine-tuned sentiment model now edges past base FinBERT, an LLM aspect classifier is ready that nearly doubles aspect accuracy, and Opus 5.5 labelled our 1,277 sentences as an extra rater. Three decisions and one overdue task need the team.

What was done today

  • Sentiment modelfine-tuned FinBERT

    Found that the class weights our docs described had never been applied: every model before today trained with plain cross-entropy. Fixed, and made weighting an option.

    Tested four changes by 5-fold cross-validation. One helped: giving the model the aspect's readable name ("Dividend Policy") instead of its key (dividend_policy). Three models trained with it are saved with checksums.

  • Aspect classifierlocal LLM, DESIGN 16

    Built and scored against our 1,277 human aspect labels. llama3.1:8b picks the human's aspect 73% of the time, qwen3:4b 72%. Nothing was written to the database: running it on the corpus is a team call.

  • Opus 5.5 labellerextra rater, DESIGN 22

    Opus labelled all 1,277 sentences: the aspect without seeing ours, then sentiment given our aspect, using our annotation guideline as its instructions. An audit of all 22 raters' file access confirmed none saw a human label.

    Our labels are unchanged. Disagreements are queued for us to review.

  • Preprocessing checkdry run

    Only 98 of 44,345 sentences (0.22%) are PDF debris. Better cleaning won't move the model; its errors are elsewhere.

  • Clean-copy installREADME test

    A fresh clone works end to end on Python 3.14. It fails on a Mac's built-in Python 3.9 with an unhelpful error; the README now says 3.10 or newer is required.

  • Docs and housekeeping

    README, STATUS, RUNBOOK, both specs, HANDOFF and the checklist brought up to date. The AI usage declaration now covers 26 Sep to 1 Oct. Everything is on main (d4a1418); all 479 tests pass.
