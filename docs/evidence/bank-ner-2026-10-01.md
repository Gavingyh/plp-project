# Bank entity recognition: built, gold sheet ready for labelling

DESIGN decision 18 and PLAN section 7: recognise organisation mentions and
resolve each to DBS, OCBC, UOB or "not the bank", evaluated against alias
matching on a ~200-sentence gold set. Built 2026-10-01 in
`preprocess/bank_ner.py`; the gold set is blank, waiting for people. Nothing
was written to the database.

```bash
.venv-plp/bin/python3 -m preprocess.bank_ner export-gold      # data/labeled/ner/gold_sheet.csv
.venv-plp/bin/python3 -m preprocess.bank_ner corpus-diff      # where it disagrees with alias matching
.venv-plp/bin/python3 -m preprocess.bank_ner evaluate         # once the gold sheet is labelled
```

## How it works

1. **Recognition**: spaCy's `en_core_web_sm` with an entity ruler placed
   before its statistical NER. On its own the pretrained model gets the
   project's hard cases wrong: in "UOB Kay Hian raised its target for OCBC"
   it tags "Kay Hian" as a person; in "DBS Vickers charges 0.12%" it keeps
   only "Vickers"; it misses lowercase "dbs". The ruler marks those names
   first, case-insensitively.
2. **Resolution**: one table (`RESOLUTION`) maps a mention to a bank or
   `NOT_BANK`, first match wins:

   | name | resolves to | why |
   |---|---|---|
   | POSB | DBS | DBS's retail brand; alias matching never sees it |
   | Bank of Singapore, Great Eastern | OCBC | OCBC subsidiaries |
   | UOB Kay Hian (also "UOBKH", "KayHian") | not the bank | a separate broker |
   | DBS Vickers | not the bank | PLAN section 7 groups it with the brokers |
   | Aston Martin DBS, deep brain stimulation | not the bank | not banks |
   | DBS, OCBC, UOB, their tickers and full names | that bank | |

3. **Fallback**: names glued to punctuation ("DBS/", "OCBC+Sti", "UOB$",
   "D05.SI", "www.ocbc.com") are one token to spaCy, so neither the ruler nor
   the model sees them; a gazetteer pass catches any bank name outside an
   entity already resolved, and skips names inside a not-the-bank name
   found in the raw text ("DBS Vickers/").

## Where it changes attribution on the corpus

Run over all 44,345 sentences (no database write): NER and alias matching
name a different set of banks for **714** sentences (1.6%).

| alias matching → NER | sentences |
|---|---|
| DBS → none | 454 |
| UOB → none | 135 |
| OCBC → DBS + OCBC | 45 |
| UOB → DBS + UOB | 38 |
| none → OCBC | 25 |
| none → DBS | 7 |
| DBS → DBS + OCBC | 6 |
| other combinations | 4 |

By cause: DBS Vickers 456, UOB Kay Hian 132 (105 written with a space, 26
as "KayHian", 1 as "UOBKH"), POSB 88, Great Eastern 19, Bank of Singapore 9,
Aston Martin 1, and ticker codes in portfolio lists 9 (O39 4, D05 3, U11 2),
which alias matching only knows with the ".SI" suffix. The first version without the fallback dropped 18 OCBC
sentences such as "www.ocbc.com" and "OCBC+Sti"; the fallback recovers them
(tests in `tests/test_bank_ner.py`).

## A decision for the team

DBS Vickers is the largest change (456 sentences). PLAN section 7 groups it
with UOB Kay Hian as a broker, so it resolves to "not the bank"; but unlike
UOB Kay Hian it carries the bank's own name, and the Opus labeller and the
annotators treated DBS Vickers trades as wealth or retail banking (see
[opus-labeller-2026-10-01.md](opus-labeller-2026-10-01.md)). If the team
counts it as DBS, change the `vickers` line in `RESOLUTION` before the gold
set is scored.

**Checked on 2 Oct.** DBS Vickers Securities (Singapore) Pte Ltd is a DBS
subsidiary: it and its holding company are in DBS Group's list of
subsidiaries at 31 Dec 2024 ([DBS](https://www.dbs.com/iwov-resources/images/investors/other-materials/2025/list-of-subsi-and-assoc.pdf)). PLAN section 7's reason for
the rule, "brokers, not the bank's own business", holds for UOB Kay Hian,
which is separately listed on SGX (U10) with UOB holding about a third
([Simply Wall St](https://simplywall.st/stocks/sg/diversified-financials/sgx-u10/uob-kay-hian-holdings-shares/ownership)), but not for DBS Vickers. Of the 456
sentences, 451 are Reddit posts by customers about using it as their broker:
fees, paying upfront, CDP, SRS, the app. None of the twelve with words such
as "analyst" or "recommend" is research about another bank. The rule the
project already applies to POSB, PayLah! and Great Eastern (subsidiaries
count as the parent) therefore counts DBS Vickers as DBS. Changing it also
changes the Opus comparison below, since Opus was given the current rule.

Applying NER to the corpus (re-attributing the 714 sentences) changes the
`sentences.bank` column and every index figure after it, so it is a team
decision, after the gold set says how accurate it is.

## A provisional reference: Opus 5.5 on the gold sheet (2 Oct)

Until people label the gold sheet, Opus 5.5 labelled it blind as a stand-in
(DESIGN decision 22: it never replaces people's labels). Four subagents, one
batch of about 50 each, given the README's rules and the sentences without
the `case` column; transcripts audited (16 tool calls, none outside each
rater's own files).

```bash
.venv-plp/bin/python3 -m train.opus_labels extra merge ner && .venv-plp/bin/python3 -m train.opus_labels extra score ner
```

| against Opus | precision | recall | F1 | exact set |
|---|---|---|---|---|
| alias matching | 0.690 | 0.876 | 0.772 | 126 of 201 (0.627) |
| NER | 0.993 | 0.993 | 0.993 | 199 of 201 (0.990) |

By stratum, alias matching fails where expected (UOB Kay Hian exact 0.10,
DBS Vickers 0.07) and NER matches Opus on every Kay Hian, Vickers, Great
Eastern, lowercase "dbs" and random sentence. The two disagreements are NER
errors on reading: "DBS - Dumbest Bank of Singapore" (NER adds OCBC for
"Bank of Singapore") and "from DBS/POSB into OCBC360" (NER misses OCBC
joined to "360"; the gazetteer fallback didn't allow a trailing number).

**Fixed the same day.** The fallback now accepts a name followed by a digit.
NER then matches Opus on 200 of 201 (F1 0.997); the remaining one is the
"Dumbest Bank of Singapore" joke, left alone. On the corpus, NER and alias
matching now differ on **763** sentences (1.7%), 49 more than the 714 above:
the sentences with a name joined to digits, such as "OCBC360", which alias
matching also misses.

**What this does and doesn't show.** Opus was given the same rules that
`RESOLUTION` encodes, so close agreement says the code applies those rules
the way a careful reader does. It doesn't say the rules are right (DBS
Vickers above), and it isn't a human measurement: report it as NER against
an LLM reference until the gold set is labelled. The labels are in
`data/labeled/claude/ner/opus_ner.csv`; don't open them before labelling the
gold sheet.
