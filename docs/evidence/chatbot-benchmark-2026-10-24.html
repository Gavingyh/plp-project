Quality review: Codex-assisted review against actual tool results and the database; not independent human ratings. 1 = major issue; 2 = partial / minor issue; 3 = satisfactory. Faithfulness = supported claims; relevance = matches request; correctness = right facts and periods. Prepared guard replies have faithfulness N/A.

What changed

  • Faster: median response 12.57 s → 4.07 s (3.1× faster). Simple lookups meet 5 s in 20/51 turns.
  • More complete: answer pass rate 99/159 (62%) → 148/159 (93%); overall queries and follow-ups are more consistent.
  • Still needs work: 11 OpenAI turns miss the quality bar, mainly incomplete or unhelpful evidence. A provider switch alone does not resolve retrieval quality.

Comparison limit: local sees full local evidence; OpenAI withholds Reddit, CNA, broker-research and unknown-source text, links/citations, and earlier assistant answers. Evidence availability differs, so this measures the configured systems rather than isolating model ability. OpenAI timings include internet latency.

Complete FastAPI response time includes local intent classification, tools, generation and verification; browser rendering is excluded. First-request probes: local 25.86 s, OpenAI 6.87 s, excluded above. OpenAI had a prior pilot, so its probe is not a cold-start comparison. Cost is a token-based estimate, not an invoice.

Test conditions, scoring and downloadable data

32 existing single questions + 18 conversation turns + 3 broader comparisons; each repeated three times in the same fixed sequential order. Conversation resets between scenarios. The existing Llama 3.1 8B intent classifier, topic taxonomy, retrieval tools and database are unchanged. Temperature 0.2; verification enabled with one rewrite. No extra HTTP retries were added by the runner; existing backend retries remain part of measured time.

Apple M2 Pro · 16 GB RAM. Local answer inference uses Ollama; hosted answer inference uses gpt-6-luna through OpenAI Chat Completions with reasoning effort none. Prepared scope replies do not call a hosted answer model. Three repeats are descriptive, not 159 independent questions or an SLA.

Answer pass requires a complete, correct and relevant response without material unsupported claims. Evidence pass requires relevant supported evidence for all requested parts, not simply a successful search. A response may be faithful to the wrong tool selection yet incorrect for the question. Identical final answers, tool results, state and expectations share a review; token usage and provider metadata do not change that review.

Speed counts and correct-and-on-time counts are reported separately. All 159 warm responses per arm were rated; prepared guard replies are omitted only from the faithfulness mean. Displayed verification flags are recorded separately and do not establish quality. Faithfulness is assessed against the evidence actually visible to the answer model.

Warm OpenAI token usage: 1,161,774 input, including 1,028,995 cached; 29,198 output; 324 provider calls. With the separate probe: 326 provider calls and ≈$0.038330. Per million tokens: US$0.10 input, US$0.01 cached input, US$0.50 output. Official model pricing. Cached input was 88.6% of input; the same usage at uncached input rates would be ≈$0.1315. Earlier pilot and smoke tests are excluded. Account sharing settings were not changed.
